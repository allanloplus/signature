# Allan & 阿拉蕾 文件簽核工坊

純前端的文件簽核工具：在瀏覽器裡把簽名圖放到 Word / PDF / 圖檔的任意位置，匯出成 PDF 或圖檔。
文件與簽名都只在瀏覽器記憶體中處理，**不會上傳到任何伺服器**（CSP 以 `connect-src 'self'` 強制）。

## 功能
- 支援 PDF、Word（.docx）、PNG / JPG；PDF 匯出保留原始向量內容，簽名另外疊上。
- 點選簽名 → 點文件位置放置；可拖曳、縮放、跨頁移動、刪除；可重複簽多處。
- 簽名資訊章（簽核人／職稱／日期／事由）、日期章。
- 選配：簽名下方加註「時間＋文件指紋」、附加含原始檔 SHA-256 的簽核紀錄頁。
- 手機友善：底部工具抽屜、加大觸控把手、可手寫簽名。

## 兩種模式
| | 分享模式（預設） | Allan 專屬模式 |
|---|---|---|
| 簽名來源 | 範例簽名，或使用者自行上傳／手寫 | 加密保險箱內的 Allan 簽名 |
| 進入方式 | 直接開啟網址 | 右上角「Allan 專屬」＋通關密語（或網址加 `#allan`） |

### Allan 簽名的保護方式
- 版本庫與網站中**沒有** Allan 的簽名原圖。
- 簽名以 PBKDF2-SHA256（600,000 次）＋ AES-256-GCM 加密成 `allan.vault.json`，只有輸入通關密語才能在本機解開。
- 解密後只存在記憶體；可手動上鎖，閒置 10 分鐘自動上鎖並清除未匯出的簽名。
- 密語輸入錯誤採指數延遲。

首次使用：「Allan 專屬」→「保險箱管理」→「建立保險箱」，選擇中英文簽名圖並設定通關密語（至少 12 字元）。
加密後的保險箱會記在該瀏覽器，並下載一份 `allan.vault.json` 備份；換裝置時用「載入保險箱檔」即可。
也可將 `allan.vault.json` 放到 `vault/` 讓所有裝置自動取得（公開版本庫時，安全性完全取決於密語強度）。

### 限制
- 這是「影像簽核」，不是具法律效力的數位憑證簽章（PAdES）。
- 已簽出的文件上的簽名影像仍可能被擷取；「時間＋文件指紋」註記可降低被挪用的風險。
- Word 由瀏覽器重新排版，分頁可能與 Word 略有差異；要求版面完全一致時，請先另存 PDF。不支援舊版 .doc。

## 部署
靜態網站，無需建置。以 GitHub Pages（或任何 HTTPS 靜態主機）發佈根目錄即可。
本機測試：`python3 -m http.server` 後開啟 `http://localhost:8000`。
