# Allan's簽名工作坊

純前端的文件簽核工具：在瀏覽器裡把簽名圖放到 Word / PDF / 圖檔的任意位置，匯出成 PDF 或圖檔。
文件與簽名都只在瀏覽器記憶體中處理，**不會上傳到任何伺服器**（CSP 以 `connect-src 'self'` 強制）。

## 功能
- 支援 PDF、Word（.docx）、PNG / JPG；PDF 匯出保留原始向量內容，簽名另外疊上。
- 點選簽名 → 點文件位置放置；可拖曳、縮放、跨頁移動、刪除；可重複簽多處。
- 簽名資訊章（簽核人／職稱／日期／事由）、日期章。
- 選配：簽名下方加註「時間＋文件指紋」、附加含原始檔 SHA-256 的簽核紀錄頁。
- 手機友善：底部工具抽屜、加大觸控把手、可手寫簽名。

## 簽名檔的保存方式
- 第一次使用時上傳（或手寫）簽名，系統會自動去白底並存在**該裝置瀏覽器的本機儲存空間**；之後開啟即可直接使用，不必再上傳。
- 簽名不在版本庫、也不會上傳到任何伺服器，因此每台裝置（電腦、手機）各需上傳一次。
- 分享網址給別人時，對方看到的是範例簽名，需自行上傳自己的簽名；拿不到你的簽名。
- 注意：清除瀏覽器網站資料、使用無痕模式會讓已存的簽名消失；能使用該裝置瀏覽器的人也能使用已存的簽名，請搭配裝置螢幕鎖。

### 限制
- 這是「影像簽核」，不是具法律效力的數位憑證簽章（PAdES）。
- 已簽出的文件上的簽名影像仍可能被擷取；「時間＋文件指紋」註記可降低被挪用的風險。
- 分享縮圖（`assets/og.png`）的網址預設為 `https://allanloplus.github.io/signature/`，若部署到其他網址請修改 `index.html` 的 `og:` 標籤。
- Word 由瀏覽器重新排版，分頁可能與 Word 略有差異；要求版面完全一致時，請先另存 PDF。不支援舊版 .doc。

## 部署
靜態網站，無需建置。以 GitHub Pages（或任何 HTTPS 靜態主機）發佈根目錄即可。

### 不架站，直接開 `index.html` 可以嗎？
可以。在電腦上直接雙擊 `index.html` 即可簽核 PDF、Word、圖檔，簽名也會保存在本機。
以下情況才需要透過網站（HTTP/HTTPS）開啟：
- **未內嵌中文字型的 PDF**：直接開檔時中文會顯示成空白（瀏覽器禁止本機頁面讀取 `vendor/cmaps/` 字碼檔）。
- **手機使用**：手機需要網址才能開啟。
- **分享連結與分享縮圖**：只有部署到網站後才有作用。

若只想在本機用網站方式開啟（非必要）：執行 `python3 -m http.server` 後開啟 `http://localhost:8000`。
